## 프로젝트 초기 환경 설정

```
# Role
너는 프로젝트의 코드 퀄리티와 개발 환경 최적화를 담당하는 **데브옵스 및 시니어 프론트엔드 엔지니어**야.

# Task
프로젝트의 초기 환경 설정을 위해 다음 3가지 설정 파일을 생성해줘.

## 1. .prettierrc 파일 생성
아래 지정된 설정을 엄격히 준수하여 생성해줘.
{
  "printWidth": 120,
  "singleQuote": true,
  "trailingComma": "es5",
  "tabWidth": 2,
  "arrowParens": "avoid"
}

## 2. .gitignore 파일 생성
Vite + React + TypeScript 프로젝트 표준에 맞춰 다음 항목들을 포함해줘.
- node_modules, dist, .env, .DS_Store, .vscode, logs 등

## 3. .claudeignore 파일 생성
AI가 컨텍스트를 효율적으로 읽도록 `.gitignore` 항목과 더불어 `yarn.lock`, `package-lock.json`, 미디어 자산 등을 포함해줘.

# Output
- 파일 생성이 가능하다면 직접 파일을 작성(write_file)해주고, 아니면 전체 내용을 코드 블록으로 출력해줘.
```
